# demosaas

### 2. «Пульс» — лендинг SaaS-аналитики для селлеров (`saas-landing/`)

Тёмный современный лендинг в стиле B2B-продуктов:

- «Живой» дашборд-мокап: CSS-графики, анимированные столбцы, плавающие карточки
- Переключатель тарифов месяц/год с плавной анимацией цен
- Анимированные счётчики метрик при скролле
- FAQ-аккордеон на нативном `<details>`
- Слайдер отзывов, две формы заявки с валидацией e-mail
- Градиентные акценты, reveal-анимации, мобильная адаптация

- Проект — демонстрационый для портфолио: заказы и заявки никуда не отправляются,
все данные хранятся только в браузере посетителя.
